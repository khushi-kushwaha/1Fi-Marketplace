# 1Fi Marketplace

A responsive marketplace experience developed as part of the **1Fi SDE Intern Assignment**.

The project extends the 1Fi Shop experience with a new **1Fi Marketplace** section where users can browse products, view product details, select variants, and explore EMI options.

## Features

- Responsive 1Fi-inspired Shop UI
- Top Brands, Nearby Stores & Marketplace tabs
- Product search and category filtering
- Dynamic product listings
- Product detail pages
- Color and storage/memory selection
- Dynamic product pricing
- Multiple EMI plans
- EMI calculation based on tenure and interest rate
- EMI selection summary
- Smooth confirmation bottom sheet
- Empty and product-not-found states

## Tech Stack

- React.js
- JavaScript
- Vite
- Tailwind CSS
- React Router
- Lucide React

## Run Locally

```bash
git clone <your-repository-url>
cd <project-folder>
npm install
npm run dev
```
